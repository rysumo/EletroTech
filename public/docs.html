Documentação de Integração & API

A Eletrotech disponibiliza endpoints padronizados, suporte a negociação de conteúdo Markdown para agentes inteligentes e interfaces via Model Context Protocol (MCP) para automação e supervisão.

1. Model Context Protocol (MCP)

Agentes de inteligência artificial (como Claude, ChatGPT e assistentes autônomos) podem se comunicar nativamente com os serviços da Eletrotech através do manifesto MCP localizado em: 

GET /.well-known/mcp
Transport: Streamable HTTP (https://eletrotech-marechal.vercel.app/api/mcp)

2. Negociação de Conteúdo Markdown

Todas as requisições enviadas com o cabeçalho Accept: text/markdown recebem representações otimizadas para processamento por LLMs sem a sobrecarga de renderização HTML: 

curl -H "Accept: text/markdown" https://eletrotech-marechal.vercel.app/

3. Especificação OpenAPI 3.0

A especificação OpenAPI completa de nossos endpoints de catálogo e telemetria está disponível em formato JSON:
Acessar /api/openapi.json
